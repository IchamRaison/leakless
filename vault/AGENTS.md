# Instructions des agents PIPE

Icham

Ce dépôt est uniquement le vault partagé du projet PIPE. Il doit suffire pour travailler sans le chat. Code et entraînements appartiennent au dépôt https://github.com/IchamRaison/ehl-hackathon-zurich ; ne pas installer les composants produit dans ce vault.

Avant d'agir, lire dans cet ordre :
1. Accueil.md et 01 Projet/Passation.md.
2. 01 Projet/Plan directeur agents.md et 01 Projet/Brief et contraintes.md.
3. 03 Build/Architecture.md, 03 Build/Contrats techniques.md et 03 Build/Protocole évaluation.md.
4. 06 Agents/Coordination et passation agents.md.
5. Votre fiche dans 06 Agents : Agent Icham - ML.md, Agent Nevil - Data.md, Agent Safoan - Application.md ou Agent Vincent - Baseline.md.

Si le rôle n'est pas fourni par le responsable, le demander avant de prendre un chantier réservé. Les fiches définissent interfaces, chemins propriétaires, livrables, tests et conditions d'arrêt. Les commandes proposées ne sont pas forcément implémentées. Vérifier le dépôt réel, ne jamais annoncer un test ou modèle inexistant.

Mettre continuellement à jour le vault après une avancée, décision, test ou blocage, avant de rendre la main, sans rappel. Chacun tient son Journal personnel dans 06 Agents et coordonne les changements de Passation/Tableau de bord. Notes en français avec Icham sous le titre. Distinguer prévu, implémenté, exécuté et vérifié ; ajouter commandes, commits, artefacts et prochaine action.

Le vault dédié est la source de vérité. Intégrer les modifications distantes avant édition ; ne pas écraser les contributions d'équipe avec le miroir ancien du dépôt code. Pas de synchronisation automatique. Aucun secret, gros dataset ou checkpoint ici. Respecter limites de budget, licences et protocole de split ; pas de résultats fabriqués ou prompts révélant les labels.
